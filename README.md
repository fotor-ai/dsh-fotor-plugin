# Fotor for DeepSeek Harness

This public repository distributes reviewed, script-free Fotor Bundle snapshots for DeepSeek Harness (abbreviated as `dsh` in commands).

The default branch currently contains this distribution notice and the license only. It is not yet an installable plugin. Test snapshots will be available on `release/test`; production content reaches `main` through a reviewed pull request. Check that a selected channel contains the complete package before installing.

The external mcp-remote bridge is installed separately; installing the Bundle does not install or authorize it.

See the [multi-platform Fotor project](https://github.com/fotor-ai/fotor-agent-plugins) for other hosts.
